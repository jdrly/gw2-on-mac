# 0.2 defaults to Metal 4, presented through a Metal 3 command buffer

Decided 2026-11-13. Status: accepted. It supersedes the Metal 3 default of 2026-11-12.

On the arm64 engine my DXMT fork's Metal 4 path stuttered whenever the cursor moved (jdrly/dxmt
#223). On 2026-11-12 I asked for a *Metal* row in Settings to go between Metal 3 and Metal 4 while
the bug was being found, and its default was Metal 3 (#136). The next day the cause was known: how
macOS hands a Metal 4 present's drawable back. Five present orders behaved the same, and only a
present through a Metal 3 command buffer was flat (`DXMT_MTL4_PRESENT=mtl3`). With it, Metal 4 ran
about 58 fps median on my Lion's Arch laps against about 50.5 on Metal 3. So the default became
Metal 4 with that present, for every install.

## Consequences

- With the *Metal* row at Metal 4, the game's rule carries `DXMT_MTL4_PRESENT=mtl3` right after
  `DXMT_METAL4=1`, in release and development builds alike, and `CefHost.exe`'s rule unsets it.
- The entry goes in only while my DXMT fork's tree in the engine names the switch. With an older
  tree there's no entry, and `status` says why.
- A new install has `metal=4`, and a `settings.conf` without the key reads 4. A file that has
  `metal=` keeps it. A choice of mine is never overwritten.
- The `dev-switches.conf` table lost its `DXMT_MTL4_PRESENT=mtl3` row. A line I changed still wins,
  because the file's lines come after the rule's entries.
- The session report says which present ran on Metal 4.
- The row's text stays: "Metal 4 is the newer path. Switch to Metal 3 for better backwards
  compatibility."
- 0.1.x is not touched. It sets neither switch and runs my DXMT fork's native Metal 4 present, which
  is flat there. The DXMT fork's ADR 0008 is the driver's side of this.
- A `compatdb.local` line of mine still wins, because it comes last.

## Alternatives I rejected

- **Metal 3 as the default.** The interim default of #136. It doesn't stutter, and it ran about 7
  fps lower on the same laps. That is one Metal 3 run.
- **Plain Metal 4.** It saws between one and two refreshes while the cursor moves.
- **`mtl3` only as a line of the dev switches file.** That was its state for one day. I wanted it
  for every install.
