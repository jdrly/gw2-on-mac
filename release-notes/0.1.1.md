## GW2 on Mac 0.1.1

Steam now quits along with the game, and the window shows how the game's start is going.

### Steam quits when you quit the game
When Play started Steam in the background, Steam now quits by itself once Guild Wars 2 has quit,
so you no longer have to quit it from the menu bar. It waits 30 seconds first, in case the game's
patcher or a restart starts the game again. A Steam that was already running, or whose window
you opened, stays open. *Quit Steam when the game quits* in Settings › Game turns this off; it
shows while *Start Steam in the background* is on.

### See how the game's start is going
After Play, the window follows the start instead of going quiet: Starting Steam, Updating Steam
and Checking game files (only when Steam does them), Signing in, Starting Guild Wars 2 and
Loading, each with what it's doing and the time so far. Then Playing shows how long you have
played, with *Bring to Front*.
- If Steam is waiting for you to sign in, *Show Steam* brings its window up. A Steam you
  brought up this way stays open after the game.
- On ArenaNet's route the stages start at Starting Guild Wars 2, and the game's launcher takes
  over from there.
- Open GW2 on Mac while the game starts or runs, and the window picks the session up.
- While Steam quits after the game, the window says *Steam is closing…* and Play waits for it.

### A steadier 60
If the game's own Frame Limiter is set while vertical sync is on, Playing suggests Unlimited
with vsync instead: under Wine, the two together land just under your display's rate, at about 58
frames per second with the limiter at 60. *Don't show again* hides the tip.

### Known limits
- While Steam verifies the game's files, *Checking game files* shows no percentage, because
  Steam's logs don't give one. A game update shows its progress.
