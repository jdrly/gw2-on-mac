## GW2 on Mac 0.1.3

New installs work again: the Wine engine now downloads from my own copy of it.

### The engine download is fixed
Since athei's release of the Wine engine went offline, a new install stopped at *Downloading Wine
engine* with a download error. I now host the same file, byte for byte, in
[jdrly/wine-engine](https://github.com/jdrly/wine-engine/releases/tag/cx-26.3.0-8), next to the
Wine source it was built from. athei built it from CodeWeavers' CrossOver 26.3 sources, and the
app still checks it against the same size and sha256. An install that already has the engine
doesn't change.

### A wrong file in the downloads folder
If the file in `~/Library/Caches/GW2 on Mac/downloads` under the engine's name isn't the engine,
the window now says so. It shows the file's size and the start of its sha256 next to the engine's.
GW2 on Mac renames it to `<name>.wrong` and downloads the engine itself. Before, it deleted the
file without a word.

### After updating
If your install got stuck at the engine's download, update, open GW2 on Mac and click *Install*
again.
