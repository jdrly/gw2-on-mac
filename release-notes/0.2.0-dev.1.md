## GW2 on Mac arm64 0.2.0-dev.1 (development build)

The first build of the 0.2 line, as a second app that installs next to GW2 on Mac 0.1.x.

### What this build is
0.2 moves the game to an arm64 Wine engine. This first build only gives that work an app of its
own. It still sets up the same engine as 0.1.3, so it plays the same. Later builds swap the
engine, one step at a time, and I compare each step with 0.1.x on the same Mac.

### It installs next to 0.1.x
The app is called *GW2 on Mac arm64*, with the bundle id `cz.jandrly.gw2onmac.arm64`. Dragging it
into Applications doesn't replace GW2 on Mac. It keeps its own engine, bottle, settings, caches
and logs in folders of its own:

- `~/Library/Application Support/GW2 on Mac arm64`
- `~/Library/Caches/GW2 on Mac arm64`
- `~/Library/Logs/GW2 on Mac arm64`

Nothing in GW2 on Mac's folders changes, and its settings stay its own. The window shows
*ARM64* under the wordmark, so the two are easy to tell apart.

### It is for comparing, not for daily play
Keep playing on 0.1.x. This build has no updates: it never checks for a new version, and
GitHub's latest release stays on 0.1.3.
